# 가짜 PLC (`fake_plc`)

실물 PLC(LS XBC-DR30SU) 대신 PC에서 래더를 스캔한다. PC 프로그램은 Modbus TCP로, 가짜 로봇은 배선 JSON으로 붙는다. 근거: `docs/handoff/fake-plc.md`, `docs/handoff/virtual-wiring.md`.

## 실행

```
python -m fake_plc [FILE] [--modbus-port 5020] [--wiring-port 5021] [--http-port 8878]
```

- FILE은 `.xgwx`, `.ld.txt`, `.bin`이다. 기본은 `ladder/PICKNPLACE_FULL.xgwx`다(노트에 기본값이 없다).
- 시작하면 주소 셋을 출력하고 바로 RUN한다. 열 수 없거나 미지원 요소가 있으면 STOP으로 두고 이유를 출력한다.
- 브라우저로 `http://127.0.0.1:8878`을 연다. `localhost`로 열면 거부한다. 127.0.0.1 주소만 받는다.
- 끝내기는 Ctrl+C다.

## 모니터 화면

| 항목 | 쓰는 법 |
| --- | --- |
| RUN / STOP | RUN을 누를 때마다 첫 스캔부터 다시 시작한다. P·M·T는 지우고 D는 유지한다 |
| 파일 열기 | 경로를 붙여 넣고 [열기]. 탐색기 "경로로 복사"의 따옴표는 그대로 둬도 된다. 파일을 열면 STOP이고 D를 지운다 |
| 프로그램 | 프로그램이 여럿이면 고르고 [고른 것만 실행]. 기본은 모두이고 XML 순서로 한 스캔에 돈다 |
| 렁 그림 | 32칸 격자. 닫힌 접점(a·상승은 1, b는 0), 참인 비교, 켜진 코일과 타이머를 파랗게 칠한다 |
| 디바이스 | 래더에 쓰인 P, M, T(완료 비트 · 누적 ms), D |
| 강제 입력 | P·M 비트를 1이나 0으로 정한다. 배선 입력보다 우선한다. [해제]로 푼다 |
| Modbus 기록 | 받은 요청과 응답. 최신이 위, 최근 100개 |
| 경고 줄 | 빨강은 실행할 수 없는 이유(열기 오류, 미지원)다. 노랑은 래치 미확인, 추정 요소, 여러 프로그램 순서 미확인, 분기 뒤 접점, 로봇이 둘 이상 붙음이다 |

## Modbus TCP (기본 5020)

- 국번 1. 보유 레지스터 주소 n ↔ D(1000+n). 주소 0 = D01000(상태), 주소 1 = D01001(명령).
- FC03(읽기), FC06(한 개 쓰기), FC16(여러 개 쓰기)만 받는다. 그 밖의 FC는 예외 01.
- 국번이 1이 아니면 예외 0B.
- FC03 수량이 1~125가 아니면 pymodbus 3.16.1이 요청을 풀지 못하고 0x80 01로 답한다.
- 읽기 값은 16비트로 자른다. 쓰기는 받은 값(0~65535)을 그대로 D에 넣는다.
- 읽기·쓰기는 스캔 사이에 들어간다. 쓴 값은 다음 스캔이 본다. STOP 중에도 D는 읽고 쓸 수 있다.

## 배선 JSON (기본 5021)

`docs/handoff/virtual-wiring.md` 2.3대로다. 더한 것:

- 로봇이 붙으면 바로 출력 한 줄을 보낸다.
- STOP이면 출력을 모두 0으로 보낸다. 실물의 출력 유지 설정은 확인하지 못했다.
- 로봇은 한 대만 붙인다. 연결이 하나라도 끊기면 P00004·P00005를 0으로 본다.

## 실행 규칙

- `.ld.txt`는 `tools/xgwx/sim.py`로 돈다. `.xgwx`·`.bin`은 렁 그림 해석기(`diagram.py`)로 돈다. 스캔 규칙은 둘 다 sim.py다: 첫 스캔 F0009B, 타이머 단위 T0000~T0499 100 ms · T0500~ 10 ms, 출력은 적힌 순서.
- 스캔마다 시뮬레이션 10 ms. Windows의 sleep이 거칠어도(약 16 ms) 밀린 스캔을 몰아서 돌려 평균을 맞춘다. 한 번에 10스캔까지만 돌리고, 더 밀리면 버린다.
- 렁 하나는 전위를 모두 구한 다음 출력을 위에서 아래로 실행한다(노트 3.4). 실물은 명령을 위에서 아래로 실행하므로 분기 뒤 접점이 있는 렁은 한 스캔 차이가 날 수 있다. 그런 렁은 경고 줄에 나온다.
- 지원 요소: a·b·상승(추정) 접점, 코일, SET·RST(추정), END, TON, MOV, BRST, 비교 = > < >= <=. 그 밖의 요소와 CTU·MOVP는 `미지원: 렁 n, 요소 …` 줄로 실행을 거부한다. 피연산자가 래더 원본 문법(P·M·T·D, 10진 정수, F는 F0009B만)을 벗어나도 거부한다.
- END는 그 프로그램의 스캔을 끝낸다. 다음 프로그램은 돈다.

## 장비 없이 tasks 시험 표 돌리기 (합격 시험 c)

터미널 셋에서 띄운다. 순서는 상관없다.

1. `python -m fake_plc`
2. 가짜 로봇: `python -m fake_robot` (하위 프로젝트 2)
3. PC 프로그램: `python -m picknplace_full --target tcp:127.0.0.1:5020`

그다음 `docs/tasks_1109.md` 6절 표 1~9행을 차례로 한다. 9행(PLC STOP → RUN)은 모니터의 STOP과 RUN을 누른다.
